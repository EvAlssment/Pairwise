How can we help?

Find setup guidance or report a problem with PairDesk.

Install and get started

Download the current Mac release and follow the install guide. PairDesk supports macOS 14 and later on Apple silicon and Intel.

Download and install

Account help

iOS users can delete their account from the profile menu. Enter the current password to confirm. For sign-in issues, first check that you are using the same server address as your team.

Report a problem

Open a GitHub issue with the app version, macOS or iOS version, and steps to reproduce. Do not include passwords, verification codes, private call content, or screenshots containing sensitive information.
